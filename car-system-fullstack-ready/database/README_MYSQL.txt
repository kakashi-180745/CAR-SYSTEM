MYSQL SETUP

FULL RESET:
1. Open MySQL Workbench.
2. Open database/car_ecommerce_ready.sql.
3. Run the complete script.
4. It creates database car_ecommerce and seeds cars/showrooms.

EXISTING DATABASE:
Run database/upgrade_existing.sql instead.

DEFAULT BACKEND CONNECTION:
Host: localhost
Port: 3306
Database: car_ecommerce
Username: root
Password: root

If your MySQL password is different, edit backend/src/main/resources/application.properties.
