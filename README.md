## Quick Start

### Spring Boot + MySQL / H2
```bash
cd car-system-fullstack-ready/backend
mvn clean spring-boot:run
```

### Zero-Setup Portable Backend (Node.js 22+ & SQLite)
```bash
cd car-system-fullstack-ready/backend-lite
npm install && npm start
```

### React + Vite Frontend
```bash
cd car-system-fullstack-ready/frontend
npm install && npm run dev
```
